# Навигация по программе

## 1. Регистрация

- Проходите простенькую регистрацию, указывая почту, логин, пароль. Нажимаете на кнопку зарегистрироваться, после попадете на основную страницу
- реализована функция скртия пароля по умолчанию и раскрытия его по кнопке "Показать пароль"
- Также можно **Войти**, если аккаунт уже зарегистрирован нажав на тект *Уже есть аккаунт? Войти*
registerform
![Форма-регистрация](/readme_source/registrationForm.png)

## 2. Вход

- всё точно также как и в форме регистрации, только доступна функция *Forgot password?*, выводя на экран следующую форму
![Форма-вход](/readme_source/forgotPassword.png)
где можно отправить свой email и вам придет письмо с автоматически сгенерированным новым паролем, по которому можно войти в программу

## 3. Основная страница

- После успешной регистрации/входа произойдет переход на основную страницу, где изображено:

*Верхняя панель:*
1. **Выпадающий список:**
![Выпадающее-меню](/readme_source/dropDownMenumenu.png)
- Раскрывает опции **About/help** и **Logout**. 1 опция перенесет на сам репоситорий с readme, чтобы пользователь мог ознакомиться с программой, 2 опция выйдет из аккаунта и перекинет на форму рестрации/входа
2. Кнопка **Проводник**
- По нажатии кнопки откроется диалоговое окно проводника, с помощью которого можно выбрать текстовики для работы
3. Кнопка **Выбрать**
- По нажатию кнопки выберутся файлы из основного меню, о котором будет рассказано ниже
4. Текстбокс **Путь**
- Показывает путь раскрытия древа папок в 1 меню
5. Кнопка **Шаблоны**
- Перенесет на форму выбора/создания шаблонов, для автоматизирования работы с программой

*Основной контент страницы*
1. Меню **Имя**:
- Тут реализован интерфейс как в WinRAR по раскрытию директорий в программе. Сама программа отображает только директории и файлы расширения **.txt**, потому что программа нацелена на то, чтобы обратывать текстовые файлы. Также реализована функция перетаскивания файлов в этот блок из вне.
2. Меню **Меню**
- Представляет собой каталоги функций, которые реализовывает программа. при нажатии на пункты меню раскрывает в 3 столбце **чекбоксы**, которые олицетворяют собой уже конкретные функции, которые может реализовывать программа, кратко о каждой из них.
*Сортировки:*,
    - По домену A-Z - сортировка по доменам стра ("BR" "RU" "FR" "UK" и т.д.)
    - По числам - сортировка по числам
    - Выполнить обратную сортировку - reverse всех выбранных пользователем сортировок
*Обработки строк:*
    - Удалить повторы - удаление повторяющихся строк 
    - Удаление строк по КС - если строка содержит введенное ключевое слово, то программа удалит эту строку
    - Удаление строк без КС - если строка не содержит введенное ключевое слово, то программа удалит эту строку
    - Удаление содержимого до КС - если строка содержит введенное ключевое слово, то программа удалит всё до этого слова в каждой строке с КС
    - Удаление содержимого после КС - если строка содержит введенное ключевое слово, то программа удалит всё после этого слова в каждой строке с КС
*Работа с другими файлами*
    - Разность текстовиков - при активации пользователь выбирает n текстовиков и программа уберет все повторяющиеся строки в первом текстовике со вторым
    - Объединение по имени файла - Когда пользователь выбирает n текстовиков и активирует эту функцию, то программа объединит только те, что имеют одинаковое имя
*Работа с одним файлом*
    - Разделение текстовика на части - пользователь указывает либо количество строк в тексовике либо количество текстовиков, нв уоторые надо разделить текстовик/и. (если брать 1 текстовик в 100 строк: если пользователь выберет по 25 строк в текстовик - создаст 4 текстовика и так далее)
3. Кнопка **Сохранить**
    - при нажатии на кнопку с выбранными опциями вам нужно будет указать название для файла, путь, и нужно ли объединение файлов в один.
## 4. Форма шаблонов

- при попаданию на форму шаблонов у вас выпадает два выбора: создание нового шаблоны или выбор уже созданных вами файлов:
![Форма-вход](/readme_source/templatesForm.png)
- при выборе создания собственного шаблона раскроется форма с тем же набором функций, которые вы можете задать самостоятельно, создав собственный шаблон для работы с текстовиками
- удаление шаблонов происходит по нажатию ПКМ

# Админ панель 

- если ввести на форме входа логин и пароль **"admin"** вам откроется не основная страница, а админ панель, где будут все пользователи и их шаблоны
- реализована функция **""Забанить?** которая удаляет аккаунт пользователя
- если нажатать на пользовательские шаблоны (реализованы кнопками), то откроется MessageBox, в котором будут все опции, что конкретный пользователь выбрал

# Устройство БД

Разделена на 3 таблицы:
- **users** - информация о пользователе (user_id, email, login)
- **users_pwd** - вынесен пароль на отдельную таблицу и захеширован с помощью внутреннего инструмента BCrypt (user_ID, salt, hashed_password)
- **templates** - вся информация о шаблонах пользователей (user_id, iD, Name, SortOptions, ProcessOptions, WorkWithFilesOptions, KeywordSorting, KeyWordDelLines, KeyWordWithoutDelLines, KeyWordAfterDelContent, KeywordBeforeDelContent, txtDifference)
